# 📱 Eventify - Mobile Event Management App
### UI/UX Design Internship Tasks — CodeAlpha

Eventify is a mobile event management application that allows users to discover, book, and manage event tickets seamlessly. This repository showcases the UI/UX design tasks completed as part of my **CodeAlpha UI/UX Design Internship**.

## 📋 Overview

- **Internship:** CodeAlpha - UI/UX Design Internship

- **My Role:** UI/UX Designer

## 🎯 Task 1: Wireframing & Low-Fidelity Design

**Description:**  
For this task, I created low-fidelity wireframes for Eventify, a mobile event management app. The wireframes cover the complete user flow — from onboarding to event booking and ticket management — focusing on layout structure, content hierarchy, and usability before adding visual design elements.

## 🎯 Task 2: High-Fidelity UI Design

**Description:**

## 🎨 Design Highlights
- Complete user flow: Splash → Onboarding → Login → Home → Event Details → Ticket Booking → Ticket → Profile
- Deep purple color theme for strong brand identity
- Clean typography and consistent spacing across all screens
- QR/barcode-based digital ticket with seat selection feature
- Category-based event browsing (Music, Sports, Workshop, etc.)
- Mobile-first, user-friendly navigation with bottom tab bar
